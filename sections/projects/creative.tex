        \textbf{Resume AI}
    \end{twocolentry}

    \vspace{0.10 cm}
    \begin{onecolentry}
        \begin{highlights}
            \item An AI based CV screening application designed to simplify the recruitment process for HR professionals and enhance candidate experience. Users can build profile just by uploading CV and can apply for jobs. One of the unique features of this app is that the CV of the applicant gets formatted and summarized automatically to help the HR screening process. The second and most amazing feature is that automatic feedback is sent to the rejected applicant. This feedback get generated based on some selected applicants CV. This way the applicant knows why they are being rejected and where/how to improve.
            \vspace{0.1 cm}
            \item \textbf{Tools Used:} NextJS, Redux, TailwindCSS, TypeScript, Django, JWT, PostgreSQL, REST API
        \end{highlights}
    \end{onecolentry}

        \textbf{Course Assistant}
    \end{twocolentry}

    \vspace{0.10 cm}
    \begin{onecolentry}
        \begin{highlights}
            \item An allrounder helper for undergraduate students that solves real-life problems. It helps to track academic progress, share content, and group study, etc. It has 3 main features, \begin{highlights}
                \item Sharing contents like previous questions, class notes, guides etc. inside own university and department.
                \item Track academic progress and get predictions on how the results are going to be with visual graphs.
                \item The last but not least and the most important feature is the study group. An automatic group being created for courses for different sections each trimester and add relevant students automatically. Student can leave the group or turn off the auto add system. Relevant students are selected based on the academic progress data.
            \end{highlights}
            \item \textbf{Tools Used:} HTML, TailwindCSS, JavaScript, Django, JWT, PostgreSQL
        \end{highlights}
    \end{onecolentry}
